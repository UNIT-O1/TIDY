1-Click Host Registration

Because browser extensions run inside a security sandbox, Chrome requires a registered local JSON manifest to enable communication with the helper.

Windows
Run the included setup script from your TempDrop directory:
powershell -ExecutionPolicy Bypass -File "installer\windows\install.ps1"
macOS / Linux
Run the bash installer to register the manifest:
bash installer/macos/install.sh  # or installer/linux/install.sh
